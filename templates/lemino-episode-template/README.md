## 📐 โครงสร้างมาตรฐานต่อ 1 ตอน (Full Episode Architecture)
- **ความละเอียด:** 1920x1080 (1080p Full HD) @ 30.00 fps
- **มาตรฐาน Contrast:** ผ่านเกณฑ์ WCAG AA 100% (อัตราส่วน > 4.5:1)
- **การแบ่งองก์:**
  - `Opening Sequence`: 75 วินาที (5 ซีน @ 14-16s) — มีฟุตเทจเปิดหัว, ภาพรวมแผนที่/สารบัญ, ปริศนาความสูง, คำถามหลัก, และไตเติลใหญ่
  - `ACT I` ถึง `ACT VI`: 120 วินาทีต่อองก์ (5 ซีน @ 20-25s) — ลำดับหลักฐานและการสืบสวนตามไทม์ไลน์
  - **ความยาวรวม (Master Episode):** ~13 นาที 15 วินาที (23,850 เฟรม)

## 🛠️ ขั้นตอนการใช้งานต้นแบบสำหรับ Episode ถัดไป
1. **สกัดฟุตเทจ B-Roll:** ตัดด้วย ffmpeg เข้าสู่ `assets/footage/` ที่ 1080p 30fps
2. **สร้างคอมโพสิชัน:** รันสคริปต์สร้างไฟล์ HTML ตามธีมที่ต้องการ
3. **ตรวจคุณภาพ:** รัน `npx hyperframes check`
4. **เรนเดอร์:** รัน `TMPDIR=/home/keng/.tmp npm run render`
5. **รวมไฟล์มาสเตอร์:** รัน `python3 stitch_episode.py`
6. **อัปโหลดขึ้น Google Drive:** รัน `python3 upload_to_gdrive.py`
